# Megamotors — сайт (демо-версия)

Статичный сайт: `index.html` + покадровая анимация автомобиля в `frames/` (192 кадра WebP).
Сборки нет: открывается двойным кликом, публикуется на GitHub Pages как есть.

## Что внутри
- Герой: автопроигрыш облёта авто туда-обратно, можно покрутить мышью/пальцем (`SWEEP` в блоке `seqHero` — длительность одного прохода).
- Каталог лотов: сейчас демо-данные в массиве `LOTS`, вместо фото стоят заглушки «Под заказ».
- Калькулятор: ставки в объекте `CFG` — демо, заменить тарифами Megamotors и актуальными ставками таможни.
- Форма заявки пока только копирует текст (бэкенда нет).
- Светлая/тёмная тема, ключ `mm-theme` в localStorage.

## Что заменить перед запуском
1. Логотип и контакты (Telegram, WhatsApp, Viber, телефон, город).
2. Демо-лоты → данные из API/парсера.
3. Ставки калькулятора.
4. Бэкенд для формы заявки.
5. Видео/кадры героя: сейчас в кадре узнаваемая модель с шильдиком — проверить права или заменить.

## Публикация (GitHub Pages)
Settings → Pages → Deploy from a branch → `main` / root.
